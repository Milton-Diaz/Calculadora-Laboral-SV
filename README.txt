# Calculadora Laboral SV

Proyecto académico: calculadora web de prestaciones laborales y jornadas especiales de El Salvador.

## Archivos
- index.html
- style.css
- script.js

## Cómo ejecutar
1. Coloca los tres archivos en la misma carpeta.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. No requiere servidor ni base de datos.

## Publicación
Puede publicarse como sitio estático en GitHub Pages, Netlify o Vercel.

## Importante
La aplicación es informativa y académica. Para una liquidación oficial deben utilizarse las fechas exactas, salario básico y demás variables que correspondan al caso concreto. La opción de renuncia voluntaria requiere verificar los requisitos de la Ley Reguladora de la Prestación Económica por Renuncia Voluntaria.

Los valores de salario mínimo incluidos en `script.js` corresponden a las tarifas comunicadas por el MTPS desde junio de 2025:
- Comercio, industria y servicios: $408.80
- Maquila textil y confección: $402.32
- Agropecuario: $305.23

Revisar los valores antes de una presentación futura si existe una nueva actualización oficial.
